## 📋 Descripción

Este repositorio contiene el código fuente de una aplicación de escritorio diseñada para la gestión integral de clínicas veterinarias (control de mascotas, dueños y consultas clínicas). El software opera de manera **100% autónoma y sin conexión a internet**, priorizando la portabilidad y la seguridad local mediante una base de datos embebida.

## 🚀 Características Clave

*   **Arquitectura Modular:** Estructura limpia basada en el estándar de Maven (`src/main/java`).
*   **Persistencia Local Autónoma:** Gestión de datos estructurada mediante archivos de bases de datos locales independientes.
*   **Portabilidad Garantizada:** Diseñado con módulos listos para la importación y exportación masiva de expedientes.

## 🛠️ Requisitos de Compilación

*   **JDK:** Java 25 o superior.
*   **Gestor de Dependencias:** Apache Maven.
